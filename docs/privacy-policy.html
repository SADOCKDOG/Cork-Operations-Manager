Política de Privacidad

Última actualización: 19 de junio de 2026

Esta política describe cómo Cork Manager trata la información del usuario en la aplicación móvil publicada por Sdog Farm Software Factory.

Responsable

Cork Manager / Sdog Farm Software Factory
Email de soporte: soporte.sdogfarm@gmail.com

Datos que puede usar la aplicación

  • Datos de fincas, compradores, zonas, pesadas, gastos y ajustes que el usuario introduce manualmente.
  • Archivos de copia de seguridad generados por el propio usuario.
  • Estado de compra premium de Google Play para desbloquear funciones de pago.

Cómo se almacenan

La mayor parte de la información se almacena localmente en el dispositivo mediante IndexedDB y localStorage. La aplicación no requiere una cuenta obligatoria para funcionar.

Finalidad

  • Gestionar la producción, pesadas, gastos e informes.
  • Permitir copias de seguridad y restauración.
  • Gestionar el acceso a funciones premium compradas en Google Play.

Compartición de datos

Cork Manager no vende datos del usuario ni los comparte con terceros para fines publicitarios. Los datos solo salen del dispositivo cuando el usuario los exporta, comparte o restaura manualmente. Las compras integradas se procesan a través de Google Play.

Seguridad

La aplicación usa almacenamiento local para minimizar la exposición de datos. Las copias de seguridad pueden protegerse con contraseña mediante cifrado AES-GCM.

Retención y eliminación

Los datos permanecen en el dispositivo hasta que el usuario los elimine, borre la app o limpie el almacenamiento. El usuario también puede borrar copias de seguridad exportadas manualmente.

Menores

La aplicación está orientada a uso profesional y no está dirigida a menores de edad.

Cambios

Esta política puede actualizarse si cambian las funcionalidades de la aplicación o los requisitos de Google Play.

Contacto

Para dudas sobre privacidad o tratamiento de datos, escribe a soporte.sdogfarm@gmail.com.
